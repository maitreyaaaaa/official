# Client

The React workspace displays the current campaign review, draft findings, proactive review items, and evidence returned by the server. Initial loads use read-only review requests; the explicit **Check campaign** action records a local status-only review when demo writes are enabled. The workspace includes a proposal queue for pause and edit proposals, explicit approval or rejection, and resume actions. The optional assistant explains checks and lists its named-tool calls; when enabled, it can return an unsaved proposal preview that requires a separate user action to save, followed by human approval before application. Its pre-submit disclosure covers data sent to OpenAI and local status-only history. Status decisions and approval enforcement stay on the server. Background monitoring is planned, not implemented.
