# Fictional fixtures

Store only synthetic records used by the demo here. The current fixture describes Alder & Finch Commerce, a fictional multi-brand retailer, and its spring reporting release. It uses role-based source reviewers and contains no real customer or employee records. Expected outcomes are documented in [`csv-launch.json`](csv-launch.json) and [the graph model](../../docs/GRAPH-MODEL-AND-QUERIES.md). The private planning source remains in the separate planning workspace and is not required to run this repository.
