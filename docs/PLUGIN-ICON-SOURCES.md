# Plugin catalog icon sources

The 25 plugin icons in `public/plugin-icons/` are local snapshots taken on 2026-10-18. They identify the named products in the demo catalog; a displayed icon does not imply a live provider connection or endorsement. The app makes no third-party icon requests at runtime.

| Local file | Source |
| --- | --- |

| `drive.png` | [Google Drive product icon](https://ssl.gstatic.com/images/branding/product/1x/drive_2020q4_48dp.png) |
| `confluence.svg` | [Simple Icons Confluence mark](https://cdn.simpleicons.org/confluence/1868DB) |
| `outlook.png` | [Outlook.com](https://outlook.live.com/) favicon via Google's favicon cache |
| `teams.png` | [Microsoft Teams](https://teams.microsoft.com/) favicon via Google's favicon cache |
| `slack.png`, `discord.png`, `zoom.png`, `otter.png`, `fireflies.png`, `fathom.png` | Favicons for [Slack](https://slack.com/), [Discord](https://discord.com/), [Zoom](https://zoom.us/), [Otter.ai](https://otter.ai/), [Fireflies.ai](https://fireflies.ai/), and [Fathom](https://fathom.video/) via Google's favicon cache |
